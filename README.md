# Data Science Interview Knowledge Base

A personal knowledge base for preserving and continuously improving the concepts, practical techniques, interview lessons, and business thinking I develop while preparing for Data Science and Machine Learning roles.

The goal is not to memorize answers. The goal is to understand the concepts well enough to explain them clearly, apply them to unfamiliar problems, and make sound technical and business decisions.

## How To Use This Repository

Before an interview:

1. Review the relevant technical notes.
2. Review the technical question bank.
3. Review behavioral examples.
4. Read the lessons-learned document.
5. Practice explaining concepts without looking at the answers.

After an interview:

1. Record the questions I was asked.
2. Record my actual answers.
3. Identify where I struggled.
4. Improve the answers.
5. Add newly learned concepts to the appropriate notes.

This repository should grow with every interview rather than starting interview preparation from zero each time.
